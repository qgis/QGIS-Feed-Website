{% trans "How do I get a QGIS account?" %}

{% blocktrans trimmed %} Somebody invites you. There is no sign up form. An account on another QGIS site is not enough on its own. Every account here is created by an existing contributor. {% endblocktrans %}

{% blocktrans trimmed %} Ask someone who already writes for the feed, or ask a feed maintainer. They create your account and send you a link. {% endblocktrans %}

{% trans "Someone sent me a link. What do I do?" %}

{% blocktrans trimmed %} The link signs you in once, so that you can set the account up. Do not forward it to anyone. {% endblocktrans %}

  1. {% blocktrans trimmed %} Open the link on the device you want to sign in with from now on. Your phone or your laptop both work. {% endblocktrans %}
  2. {% trans "Confirm your email address when you are asked to." %}
  3. {% trans "Create a passkey. Your device will offer to do this for you." %}

{% blocktrans trimmed %} From then on, sign in with your passkey. The link stops working. If it has already expired, ask for a new one. {% endblocktrans %}

{% trans "What is a passkey?" %}

{% blocktrans trimmed %} A passkey lets your device prove who you are, using the same face scan, fingerprint or screen lock you already use to unlock it. There is no password on your QGIS account at all. {% endblocktrans %}

{% blocktrans trimmed %} This is safer and quicker. There is no password to forget, to reuse, or for somebody to steal. A passkey also cannot be given to a fake sign in page by mistake. {% endblocktrans %}

{% blocktrans trimmed %} A passkey can live on your phone, your laptop, or a hardware key. Keep at least two, on two different devices. If you have only one and you lose it, you cannot sign in. {% endblocktrans %}

{% trans "How do I add a passkey?" %}

  1. {% blocktrans trimmed %} Open Your account from the menu under your name. {% endblocktrans %}
  2. {% trans "Choose Add a passkey." %}
  3. {% blocktrans trimmed %} Sign in as usual, then follow what your device asks. The new passkey belongs to the device you are using, so use the one you want to add. {% endblocktrans %}

{% trans "How do I remove a passkey?" %}

{% blocktrans trimmed %} Open Your account, find the passkey in the list, and choose the remove button beside it. {% endblocktrans %}

{% blocktrans trimmed %} You cannot remove your last passkey. Your account has no password, so removing it would lock you out. Add a second one first, then remove the one you no longer want. {% endblocktrans %}

{% trans "I have lost the device with my passkey" %}

{% blocktrans trimmed %} Sign in with one of your other passkeys, open Your account, and remove the one on the lost device. Do this even if the device was locked. {% endblocktrans %}

{% blocktrans trimmed %} If that was your only passkey, you cannot sign in. Ask a feed maintainer for a new enrolment link and set the account up again. {% endblocktrans %}

{% trans "Who can I invite?" %}

{% blocktrans trimmed %} People at your own level or below, never above. You cannot give someone a role higher than your own. {% endblocktrans %}

{% blocktrans trimmed %} There is also a limit on how many invitations you can have open at once. It is not a limit on how many people you may invite. Invite as many as you need, a few at a time. {% endblocktrans %}

{% blocktrans trimmed %} An invitation stays open until that person signs in, and then the place it held comes back to you. If somebody is never going to sign in, open People, find their row and free the place yourself. Their account stays and their link keeps working. {% endblocktrans %}

{% trans "How do I invite someone?" %}

  1. {% trans "Open People from the menu under your name." %}
  2. {% trans "Choose Invite, then New user." %}
  3. {% blocktrans trimmed %} Fill in their name, their email address and the role you are giving them. The account is created now. Nothing is sent yet. {% endblocktrans %}
  4. {% blocktrans trimmed %} Send them the setup email, or take the enrolment link and hand it over yourself. The link is shown once and is never stored, so copy it before you leave the page. {% endblocktrans %}
{% blocktrans trimmed %} The link signs its holder in as that person. Send it only to the person you invited. If you are in the same room, use the QR code beside it. {% endblocktrans %}

{% blocktrans trimmed %} You are responsible for the people you invite. If your access is withdrawn, theirs is suspended too. {% endblocktrans %}

{% trans "What happens if trust is withdrawn?" %}

{% blocktrans trimmed %} A maintainer withdraws trust when somebody should no longer have access, for example when they leave a role. The reason is recorded. {% endblocktrans %}

  • {% trans "That person loses every role and cannot sign in again." %}
  • {% blocktrans trimmed %} It applies to their QGIS account, so it holds across every QGIS site, not only this one. {% endblocktrans %}
  • {% blocktrans trimmed %} Everyone they invited is suspended, and everyone those people invited. {% endblocktrans %}
  • {% blocktrans trimmed %} Their published news items stay up and are still credited to them. Nothing is deleted. {% endblocktrans %}
  • {% blocktrans trimmed %} Anything of theirs waiting to be published goes back to draft. {% endblocktrans %}

{% blocktrans trimmed count counter=grace_days %} A maintainer can undo this for {{ counter }} day. After that, you need a new invitation. {% plural %} A maintainer can undo this for {{ counter }} days. After that, you need a new invitation. {% endblocktrans %}

{% trans "My account says suspended" %}

{% blocktrans trimmed %} Suspended is not the same as withdrawn. The person who invited you lost their access, so yours is paused. {% endblocktrans %}

{% blocktrans trimmed %} You can still sign in and read, but you cannot change anything. Your work is untouched. Ask a feed maintainer to restore your account. {% endblocktrans %}

{% trans "I cannot sign in" %}

{% trans "You need an invitation" %}
{% blocktrans trimmed %} Your QGIS account works, but there is no account for you on this site yet. Ask a feed maintainer to invite you, and tell them the QGIS account name you signed in with. {% endblocktrans %}
{% trans "You do not have access to that page" %}
{% blocktrans trimmed %} You are signed in, but your role does not cover that page. Sign out and in again first. If it still will not open, ask a feed maintainer to check your role. {% endblocktrans %}
{% trans "Too many sign in attempts" %}
{% blocktrans trimmed %} Wait a few minutes and try again. We slow repeated attempts down to keep accounts safe. {% endblocktrans %}

{% blocktrans trimmed %} For anything else, ask a feed maintainer. They handle roles, permissions and the account service itself. {% endblocktrans %}
